Esta atividade foi realizada como Desafio para a trilha de Analise de Dados oferecida pelo SCTEC.
O desafio busca analisar os dados públicos de uma rede varegista dos EUA chamada Sample Superstore.

Informações sobre o código:
    Os códigos comentados foram utiliados para uma analise inicial dos dados presentes no arquivo CSV.
    Todas as interpretações sobre as informações mostradas nas analises são imprimidas no terminal após
    fechar a janela dos gráficos.

Dependências:
    pandas
    numpy
    matplotlib

Forma de execução:
    Cada análise deve ser executada separadamente pelo terminal ou no ambiente google colab ao copiar 
    e colar a conteúdo e fazer os devidas alterações para abertura do arquivo csv em cada script.

    Exemplo de execução:
        python segment-analysis.py

    OBS.: O ARQUIVO initial-analysis.py FOI UTILIZADO APENAS PARA UMA ANÁLISE INICIAL DO ARQUIVO CSV, 
    ELE NÃO TRAZ NENHUMA INTERPRETAÇÃO DOS DADOS.
