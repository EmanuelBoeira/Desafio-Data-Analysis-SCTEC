Esta atividade foi realizada como Desafio para a trilha de Analise de Dados oferecida pelo SCTEC.
O desafio busca analisar os dados públicos de uma rede varegista dos EUA chamada Sample Superstore.

Informações sobre o código:
    Os códigos comentados foram utiliados para uma analise inicial dos dados presentes no arquivo CSV.
